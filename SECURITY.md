# Security policy

Report suspected vulnerabilities privately through
[Pushman's private vulnerability reporting](https://github.com/pushmanhq/pushman/security/advisories/new),
not public issues. Mention this skills repository and the affected version.

Do not include live credentials, native keyring exports, Google/Apple passwords,
pairing codes, account identifiers, notification content, or unredacted history.
Use minimal synthetic examples.

This is an instruction package, not a permission enforcement layer. Its safety
guidance complements host tool approvals and server authorization; it cannot
guarantee that every agent will follow instructions. The current published skill
release receives fixes. For service or CLI security behavior, see the
[product security policy](https://github.com/pushmanhq/pushman/blob/main/SECURITY.md).
